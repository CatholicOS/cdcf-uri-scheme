# Appendix B: Eastern Catholic *Sui Iuris* Churches (Complete List)

All 23 Eastern Catholic *sui iuris* churches, grouped by liturgical tradition.
Identifiers take the form `cdcf:institution/eastern-church/{slug}`.

| `cdcf:` slug | Church | Rite / Tradition |
|---|---|---|
| `eastern-church/coptic-catholic` | Coptic Catholic Church | Alexandrian |
| `eastern-church/ethiopian-catholic` | Ethiopian Catholic Church | Alexandrian |
| `eastern-church/eritrean-catholic` | Eritrean Catholic Church | Alexandrian |
| `eastern-church/maronite` | Maronite Catholic Church | West Syriac (Antiochene) |
| `eastern-church/syriac-catholic` | Syriac Catholic Church | West Syriac (Antiochene) |
| `eastern-church/syro-malankara` | Syro-Malankara Catholic Church | West Syriac (Antiochene) |
| `eastern-church/armenian-catholic` | Armenian Catholic Church | Armenian |
| `eastern-church/chaldean` | Chaldean Catholic Church | East Syriac |
| `eastern-church/syro-malabar` | Syro-Malabar Catholic Church | East Syriac |
| `eastern-church/albanian-greek-catholic` | Albanian Greek Catholic Church | Byzantine |
| `eastern-church/belarusian-greek-catholic` | Belarusian Greek Catholic Church | Byzantine |
| `eastern-church/bulgarian-greek-catholic` | Bulgarian Greek Catholic Church | Byzantine |
| `eastern-church/croatian-serbian-greek-catholic` | Greek Catholic Church of Croatia and Serbia | Byzantine |
| `eastern-church/greek-byzantine-catholic` | Greek Byzantine Catholic Church | Byzantine |

> **[REV-04]** Version 0.3.0 listed 14 entries under this "complete list" title, one of
> which (`melkite-jerusalem`) is not a separate *sui iuris* church: Jerusalem falls
> within the Melkite Greek Catholic Patriarchate. That entry is removed and the list now
> covers all 23 Eastern Catholic churches, consistent with the Terminology table and
> [§3.7.1](03-domains.md#371-eastern-catholic-churches).

See [§3.7.1](03-domains.md#371-eastern-catholic-churches) for the identifier pattern and
the theological rationale for representing all 24 *sui iuris* churches without
privileging the Latin Church as the default.
